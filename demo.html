About This Prototype

AI-Powered Customer Support Automation

This prototype demonstrates a full customer support automation system using Claude as the AI backbone. It classifies incoming tickets, detects sentiment, assigns priority, and drafts responses — all via a single structured prompt.


Stack

  • ⚡ Claude API (claude-opus-4-6)
  • 🐍 Python 3.11+
  • 🚀 FastAPI + Uvicorn
  • 📦 Anthropic SDK
  • 🎨 Vanilla HTML/CSS/JS
  • 📊 Chart.js (analytics)

Files

  • src/classifier.py — Core AI classifier
  • src/api.py — FastAPI REST server
  • demo.html — This interactive dashboard
  • docs/report.md — Architecture report
